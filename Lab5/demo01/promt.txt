# CORE FEATURES TO IMPLEMENT (in Program.cs)
You must implement the following Rate Limiting middleware and policies using `Microsoft.AspNetCore.RateLimiting`:

1.  **Global OnRejected Handling**: Configure the rate limiter to return Status Code 429 (Too Many Requests) and a custom message: "Too many requests. Please try again later." when a request is rejected.
2.  **Fixed Window Policy ("fixed")**: 
    * PermitLimit: 5 requests.
    * Window: 10 seconds.
    * QueueLimit: 2.
    * QueueProcessingOrder: OldestFirst.
3.  **Sliding Window Policy ("SlidingPolicy")**:
    * PermitLimit: 30 requests.
    * Window: 30 seconds.
    * SegmentsPerWindow: 3.
4.  **Authentication-Based Policies**:
    * Add a fake/mock JWT Authentication setup (just `builder.Services.AddAuthorization()`).
    * Policy "anonymous": Fixed Window, 3 requests per 10 seconds.
    * Policy "authenticated": Fixed Window, 10 requests per 10 seconds.
